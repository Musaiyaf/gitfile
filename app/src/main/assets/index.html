Create a fine-grained personal access token at github.com/settings/tokens. Grant these repository permissions: Contents → Read and write, Pull requests → Read and write, Metadata → Read.

The token is never sent anywhere except api.github.com. On a shared device, leave this off — the token then lives in memory and is gone when you close the app.
